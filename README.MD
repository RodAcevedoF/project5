# ✅ GetDoneApp – Todo, Books & Videos Manager

**GetDoneApp** is a productivity web app combining a todo list with book and video management, user profiles, weather updates, and authentication. Built in **vanilla JavaScript**, it features a custom **mini-router** and a **global state management system**, both developed from scratch.

---

## 🌐 Live Demo

🔗 [getdoneapp.vercel.app](https://getdoneapp.vercel.app/)  
📁 [GitHub Repo](https://github.com/RodAcevedoF/project5)

---

## 🚀 Features (English)

### ✅ Todo + Media Manager

- Manage todos, books (via Google Books), and videos (via YouTube)
- Save and remove favorite books and videos

### 🔐 Auth & Profile

- Email registration and login
- Email verification and password recovery
- Profile photo upload and editable user info
- Secure token flow with access and refresh tokens

### 🌦️ Extras

- Weather widget using public weather API
- Animated UI with **GSAP**
- Alerts and pop-ups via **SweetAlert2**
- Emails sent via **EmailJS**

### 🧠 Built-in Architecture

- Custom **Mini-Router** with Vercel routing support
- Lightweight **Global State System**

---

## 🛠️ Tech Stack

- Vanilla JavaScript
- GSAP, Axios, EmailJS, SweetAlert2
- Google Books API, YouTube API, Public Weather API
- Custom REST API (backend built by the developer)
